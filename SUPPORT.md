## Before reporting a problem

1. Confirm your browser is current.
2. Confirm Node.js 22+ and npm 10+ if you are developing locally.
3. Read `docs/troubleshooting.md`.
4. Reproduce the issue with a clean browser profile when practical.
5. Run `npm run check` for development problems.
6. Remove secrets and personal learner data from screenshots, logs, backups, and sample files.

## Useful issue information

Please include:

- TableSpark version or commit hash;
- operating system;
- browser and browser version;
- installed-PWA or regular-browser usage;
- exact steps to reproduce;
- expected and actual behavior;
- relevant error text after removing private information.

## Data recovery

TableSpark stores core learning data locally in the browser. Clearing site data, browser storage, or a browser profile can remove local TableSpark data. Export a JSON backup from **Settings → Data & privacy** before clearing storage or moving devices.

The project cannot recover local data that was never exported and has already been deleted from the browser.
