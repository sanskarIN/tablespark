# ADR 0001: TypeScript React PWA as the primary client

- Status: Accepted
- Date: 2026-08-19

## Context

TableSpark must run on the web and be installable on modern Windows, macOS, and Linux while remaining offline-first and easy to maintain. The product does not require privileged native APIs for its core learning workflows.

## Decision

Use a strict TypeScript React application built with Vite and packaged as a Progressive Web App. Keep multiplication, question generation, mastery, and persistence rules outside presentation components. Store learner state locally and expose explicit import/export boundaries.

## Consequences

- One web codebase serves browsers and installable desktop PWA use cases.
- Offline support is implemented through a service worker generated by `vite-plugin-pwa`.
- Native app-store packaging is intentionally outside the initial release scope.
- Browser APIs such as speech synthesis are progressive enhancements and must fail safely when unavailable.
